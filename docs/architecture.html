Request Data Flow

  1. User changes a control in FilterBar.vue — one of Time Period, Location, Category, Order Status.
  2. The bound ref inside useFilters.js updates. Because the refs are module-level singletons, every view sees the change immediately.
  3. The active view's watch fires and calls getCurrentFilters(), which maps selectedPeriod → month and selectedLocation → warehouse.
  4. client/src/api.js drops any filter equal to 'all', builds a URLSearchParams string, and issues the axios GET.
  5. FastAPI validates query params, filters the in-memory lists sequentially, and aggregates where needed (dashboard summary, quarterly reports).
  6. The response is validated against a Pydantic response_model and returned as JSON.
  7. The view stores raw rows in a ref (allOrders, inventoryItems); every derived number is a computed, so KPI cards and SVG charts recalculate automatically.

  • 404  api.js calls POST /api/purchase-orders and GET /api/purchase-orders/{id} — models are defined, routes are not

Conventions Worth Knowing

  • Reactivity Raw API rows live in refs; every aggregate is a computed. Never mutate a computed.
  • Keys v-for keys use domain identifiers (sku, month, id) — never the array index.
  • Dates Validate with isNaN(date.getTime()) before calling .getMonth().
  • Filters Inventory has no time dimension, so the month filter does not apply to it.
  • Persistence None. Mutations live in process memory; restarting the server reloads the JSON fixtures.
  • Design system Slate palette (#0f172a, #64748b, #e2e8f0), status colours green/blue/amber/red, no emojis in UI.
  • Revenue goals $800K per month, $9.6M year-to-date.
